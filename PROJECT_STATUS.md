# Register project status

The project includes the frozen literary register space (`R_lit`), source-calibrated A/B data, exploratory C and predictive D datasets, and a minimal standalone Register Card GPT prototype.

**Research status:** experimental. The ten-dimensional register space is frozen for reproducible projections, but the fingerprinting and prose-production claims are not validated. Class D fingerprints are speculative predictions, not empirical measurements.

The available GPT prototype uses a ten-dimensional numeric registry for centroid calculations and compact verbal fingerprints for display. Preferred authors form an attractive field; avoided authors form a repulsive field. Randomness is a user-facing 0–10 control governing register mobility only.

This file is a repository note, not a replacement for the full artifacts. Local artifacts could not yet be transferred by the GitHub connector in bulk.
